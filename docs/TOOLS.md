# Инструменты стека

Written for: команда. Статус: **подтверждено** (проверено на машине или в аккаунте), **получено** (доступ есть, настройка не проверена), **предложено** (решения ещё нет).

## Инфраструктура

| Инструмент | Для чего | Статус | Примечание |
|---|---|---|---|
| Hostinger VPS KVM 2 | прод-хост: 2 vCPU, 8 GB RAM, 100 GB NVMe, Docker | получено | доступ есть. IP и логин только в `.env` |
| Hostinger AI Router | одна точка доступа к 150+ моделям (Claude, GPT, DeepSeek и др.), один баланс кредитов | получено | ключ только в `.env`. Базовый URL уточнить в панели |
| Бесплатный домен Hostinger | публичный URL для судей | получено | название в `.env` (`PUBLIC_DOMAIN`) |
| Hostinger connector / API / CLI | управление VPS и DNS из редактора (Claude Code, MCP) | предложено | docs.hostinger.com/hostinger-connector, developers.hostinger.com |
| Hostinger MCP-сервер | тот же функционал через MCP | предложено | github.com/hostinger/api-mcp-server |
| Docker + docker compose | упаковка приложения | предложено | Dockerfile пока нет |
| Caddy | HTTPS на VPS | предложено | не выбран окончательно |

## Локальная машина

| Инструмент | Версия | Статус |
|---|---|---|
| Git | 2.43 или новее | нужен |
| Python | 3.12 | нужен |
| uv | актуальная версия | нужен |
| Claude Code | — | используется |

Как настроено окружение на конкретной машине, в репозитории не описывается.

## Секреты и доступ

| Что | Где лежит | В git |
|---|---|---|

| SSH-ключ к VPS | `secrets/` | нет |
| Пароли аккаунта Hostinger, 2FA | менеджер паролей / панель Hostinger | нет |
